# Звук в динамик

Android-приложение для HyperOS (и других прошивок), которое решает проблему:
при подключённых Bluetooth-наушниках звук уведомлений и звонка идёт только в наушники.

Приложение следит за уведомлениями и, пока подключены наушники, **дополнительно**
проигрывает тот же звук через динамик телефона. В наушниках звук тоже остаётся.

## Что умеет

- дублирует звук уведомлений на динамик (с учётом звука канала уведомлений, режима «Не беспокоить» и беззвучного режима);
- дублирует рингтон входящего звонка на динамик (по желанию);
- можно исключить отдельные приложения;
- регулировка громкости на динамике и кнопка проверки;
- опционально работает и с проводными наушниками.

## Как собрать APK

### Вариант 1. Без компьютера — через GitHub

1. Создайте репозиторий на github.com и загрузите в него все файлы проекта
   (папка `.github` обязательна).
2. Откройте вкладку **Actions** → **Build APK** → дождитесь зелёной галочки
   (если не запустилось само — **Run workflow**).
3. В завершённом запуске внизу, в разделе **Artifacts**, скачайте `BtSpeakerNotify-apk`.
   Внутри — `app-debug.apk`.

### Вариант 2. Android Studio

Откройте папку проекта, дождитесь синхронизации Gradle и выберите
**Build → Build APK(s)**. Готовый файл: `app/build/outputs/apk/debug/app-debug.apk`.

### Вариант 3. Командная строка

Нужны JDK 17, Android SDK (платформа 34) и Gradle 8.9+:

```
gradle assembleDebug
```

## Первый запуск

1. Установите APK (разрешите установку из неизвестных источников).
2. Откройте приложение → **Выдать доступ к уведомлениям** → включите переключатель.
   Если переключатель серый: Настройки → Приложения → Все приложения → «Звук в динамик» →
   меню ⋮ → **Разрешить ограниченные настройки**, затем повторите.
3. Включите «Дублировать звонок на динамик» и разрешите доступ к состоянию телефона
   (если нужно дублировать звонки).
4. Подключите наушники и нажмите **Проверить звук на динамике**.

## Чтобы работало стабильно на HyperOS

HyperOS агрессивно выгружает фоновые приложения. Без этого звук будет пропадать:

- кнопка **Автозапуск** → включить для приложения;
- Настройки → Приложения → «Звук в динамик» → **Экономия заряда → Нет ограничений**;
- открыть список недавних приложений и **закрепить** («замок») карточку приложения.

## Ограничения

- Отключить звук в наушниках приложение не может — звук будет и там, и на динамике.
- Дублируются только уведомления, у которых есть звук и которые система реально озвучивает.
  Звуки, которые приложение проигрывает само (например, внутри мессенджера), не затрагиваются.
- При беззвучном режиме и вибрации звук на динамик не дублируется.
- Приложение не собиралось и не проверялось на реальном устройстве в среде, где оно писалось —
  первый запуск лучше проверить и при необходимости поправить.
